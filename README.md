# Active Directory Red Team Simulation Lab

## Overview

This repository documents my learning and practical exercises in Active Directory security and offensive security within an authorized lab environment.

## Objectives

* Understand Windows Active Directory and domain architecture.
* Learn Active Directory enumeration concepts.
* Identify and understand common security misconfigurations.
* Study potential attack paths in a controlled lab.
* Document findings and recommended defensive measures.

## Tools and Technologies

* Windows Server and Windows client environments (if used)
* Active Directory
* PowerShell (if used)
* Virtualization tools (if used)

## Methodology

1. Understand the lab environment.
2. Review Active Directory users, groups, and domain concepts.
3. Assess permitted security configurations.
4. Document observations and potential risks.
5. Recommend appropriate mitigations.
